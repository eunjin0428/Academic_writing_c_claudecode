**문서 상태:** 초안 v1.2 (v1.1 프로토콜 검토 반영) · 면담 시작 전 연구책임자 확인과 IRB 승인 문구 대조 필요

**용도:** 성인 뇌전증 환자 개별 면담(concept elicitation)의 현장용 질문지. 분석 절차(코딩, 코드북, 포화 검토)는 별도 프로토콜 v1.1 §5–6을 따른다.

> **핵심 원칙.** 면담 중에는 code나 domain을 찾으려 하지 않는다. 환자가 구체적인 사례와 실제 생활에 미친 영향까지 말하도록 돕고, 분류는 녹취 후에 한다.

**표기법:** 「굵은 따옴표」 = 면담자가 그대로 읽는 문구 · `[ ]` = 확인·교체가 필요한 부분 · **필수** = 모든 면담에서 묻기 · **선택** = 시간이 남거나 환자가 관련 이야기를 꺼낼 때

# 0. 면담 전 준비

## 0.1 체크리스트

| 구분 | 확인 사항 | 완료 |
|---|---|---|
| 동의 | 서면 동의서 수령(녹음 동의 포함), 참여자 ID 부여 | ☐ |
| 장비 | 녹음기 2대(주·보조), 배터리, 저장 공간 시험 녹음 | ☐ |
| 장소 | 조용하고 사생활이 보장되는 곳, 눕거나 쉴 수 있는 곳이 가까움 | ☐ |
| 안전 | 면담 중 응급 대응자와 연락 방법 확인(§7), 상담 연계 안내문 준비 | ☐ |
| 환자 부담 | 휴식 가능 안내, 물 준비, 소요 시간 사전 고지(약 60분) | ☐ |
| 기록지 | 참여자 특성 기록지(§0.2) 사전 수집, field memo 양식 출력 | ☐ |
| 면담자 | 질문 순서보다 환자의 이야기를 따른다는 점 재확인 | ☐ |

## 0.2 참여자 특성 기록지 (면담 전·후 별도 수집, 면담 시간에 묻지 않음)

연령대, 성별, 진단 시기와 유병 기간, 발작 유형(자기보고·의무기록), 최근 발작 빈도, 항발작제 복용 수, 수술·신경자극술 여부, 직업·학업 상태, 면담 방식(대면/화상/전화), 면담 일시와 소요 시간. 표본 다양성 확인용이며 `[연구책임자 확정]`.

# 1. 시간 구성 (기본 60분)

| 시간 | 단계 | 내용 |
|---|---|---|
| 0–5분 | A. 시작 | §2 오프닝 문구, 녹음 시작 |
| 5–25분 | B. 핵심 질문 | §3 필수 질문 5개(선택 질문은 시간이 남을 때만) |
| 25–40분 | C. 심화 | §4 probe로 환자가 이미 말한 내용을 깊게 탐색 |
| 40–50분 | D. 빠진 영역 확인 | §5 해당 영역 중 **아직 안 나온 것만**, 영역당 약 1분 |
| 50–58분 | E. 우선순위 | §6 질문 |
| 58–60분 | F. 마무리 | §6 마무리 문구 |

- 피로·집중 저하가 보이면 휴식을 제안하거나 D단계를 줄인다. 2회로 나누는 방법은 `[연구책임자·IRB 확인]`.
- 중요한 이야기가 나오면 시간표보다 환자의 이야기를 우선한다. 못 다룬 영역은 field memo에 남긴다.

# 2. 오프닝 문구 (A단계)

> 「오늘은 뇌전증을 가지고 생활하시면서 어떤 경험을 하셨는지, 그리고 뇌전증 치료가 잘 되고 있는지를 살펴볼 때 어떤 점이 중요한지를 듣고자 합니다. 말씀하신 내용은 앞으로 뇌전증 환자분들에게 중요한 건강 결과를 정하고 이를 평가하는 도구를 만드는 데 활용됩니다.」

> 「정답은 없습니다. 본인의 경험이나 생각을 그대로 말씀해 주시면 됩니다. 불편한 질문은 답하지 않으셔도 되고, 언제든 쉬시거나 그만두셔도 불이익이 없습니다. 제가 질문을 드리지만 질문 순서보다 말씀해 주시는 이야기를 따라가면서 진행하겠습니다.」

> 「정확하게 기록하려고 동의해 주신 대로 녹음을 하겠습니다. `[녹음 보관·삭제 방식, 비식별화, 접근 권한: IRB 승인 문구로 교체]` 성함 등 개인정보는 제외하고 기록하고 분석합니다. 시작하기 전에 궁금하신 점이 있으신가요?」

- 질문에 답하고 **녹음을 시작한 뒤** 다음 단계로 간다.
- 면담자의 소속·역할을 밝힌다. 진료 담당 의료진이 아님을 `[해당 시]` 분명히 말한다.

# 3. 핵심 질문 (B단계) — 먼저 듣기

환자가 말하는 동안 끊지 않는다. 한 질문에는 한 가지만 묻는다.

## 3.1 필수 질문

| # | 목적 | 질문 (그대로 읽기) | 메모 |
|---|---|---|---|
| B1 | 진단 경험 | 「뇌전증이라는 이야기를 처음 들었을 때, 어떤 생각이나 느낌이 드셨는지 말씀해 주실 수 있을까요?」 그다음 「그때부터 지금까지는 어떻게 지내 오셨나요?」 | 두 질문은 따로 묻는다. 어릴 때 발병해 기억이 없으면 「기억나는 때부터」로 시작 |
| B2 | 삶의 변화 | 「뇌전증이 있는 지금의 생활을 진단 전(또는 어렸을 때)과 비교하면, 달라진 점이 있다면 어떤 것일까요?」 | 변화가 없다고 하면 그대로 받아들이고 이유를 묻는다 |
| B3 | 좋은 날·힘든 날 | 「좋은 하루와 뇌전증 때문에 힘든 하루는 어떤 점이 다른가요?」 | |
| B4 | 최근 구체적 사례 | 「최근에 뇌전증이나 치료 때문에 영향을 받았던 하루나 상황 하나를 떠올려 주실 수 있을까요?」 | 이후 §4 probe(사례·영향) |
| B5 | 치료의 의미 | 「어떨 때 ‘요즘 치료가 잘 되고 있다’고 느끼시나요? 반대로 잘 안 되고 있다고 느끼실 때는 언제인가요?」 | 발작 외의 내용이 나오는지 주의해서 듣는다 |

## 3.2 선택 질문 (시간이 남거나 해당 이야기가 나올 때)

| # | 목적 | 질문 |
|---|---|---|
| B6 | 병원 경험 | 「뇌전증 때문에 외래를 다니거나 검사·입원·치료를 받아 오신 경험은 전반적으로 어떠셨나요?」 |
| B7 | 자가관리 | 「평소 뇌전증이나 건강을 관리하기 위해 하고 계시거나 신경 쓰시는 것이 있나요?」 |
| B8 | 현재의 중요한 것 | 「지금의 삶을 전반적으로 생각하셨을 때, 가장 중요한 것과 가장 아쉬운 것은 무엇인가요?」 |
| B9 | 목표 | 「앞으로 지금보다 좋아졌으면 하거나 다시 할 수 있었으면 하는 것이 있다면 무엇인가요?」 |

# 4. 심화 probe (C단계) — 5가지만 기억

| 목적 | 자연스러운 문장 |
|---|---|
| 구체화 | 「그게 어떤 느낌인지 조금 더 설명해 주실 수 있을까요?」 |
| 사례 | 「최근에 그런 일이 있었던 구체적인 상황이 있을까요?」 |
| 영향 | 「그 때문에 실제 생활에서 달라진 것이 있나요?」 |
| 중요성 | 「그 부분이 본인에게 왜 중요한가요? 좋아지면 무엇이 달라질까요?」 |
| 변화·비교 | 「예전과 비교하면 달라졌나요? 좋은 때와 힘든 때는 어떻게 다른가요?」 |

- 막히면 새 질문을 만들지 말고 **구체화 → 사례 → 영향 → 중요성** 순서로만 간다.
- 환자의 단어를 그대로 되받는다. (예: 「‘멍하다’고 하셨는데, 어떤 느낌인가요?」)
- 면담자가 먼저 영역 이름(인지, 우울 등)을 말하지 않는다.
- 침묵은 3–5초 기다린다.

# 5. 빠진 영역 확인 (D단계)

**원칙:** 환자가 이미 말한 영역은 다시 묻지 않는다. **1차 문장**을 먼저 쓰고, 환자가 답하기 어려워할 때만 **2차 예시**를 든다. 전부 묻지 않는다.

전환 문구:

> 「많이 말씀해 주셨는데요, 제가 빠뜨린 중요한 부분이 없는지 몇 가지만 짧게 확인하겠습니다. 이미 말씀하신 내용은 다시 답하지 않으셔도 되고, 해당되지 않으면 ‘없다’고 하셔도 됩니다.」

| 영역 | 1차 문장 | 2차 예시 (필요할 때만) |
|---|---|---|
| 발작 | 「발작과 관련해 아직 말씀하지 않은 부분이 있으면 말씀해 주세요.」 | 강도, 예측이 어려움, 다침, 회복 |
| 인지 | 「기억하거나 집중하거나 생각을 이어가는 부분에서 달라졌다고 느끼시는 점이 있나요?」 | 기억, 집중, 생각 속도, 단어 찾기 |
| 정서 | 「마음이나 감정 면에서 뇌전증과 관련해 느끼시는 점이 있나요?」 | 걱정, 두려움, 우울감, 자신감 |
| 수면·피로 | 「잠이나 낮 동안의 피로·졸림 때문에 생활에 영향을 받는 부분이 있나요?」 | 원인이 병인지 약인지는 묻지 않고, 영향이 있는지만 확인 |
| 치료 부담 | 「약이나 치료를 받는 과정에서 번거롭거나 부담되는 점이 있나요?」 | 약 복용, 부작용, 병원 방문·대기, 검사, 시간, **비용**, 치료 결정 |
| 일·학업·독립 | 「일이나 학업, 이동, 혼자 지내는 일상에서 뇌전증이 영향을 주는 부분이 있나요?」 | 직장·학교 생활, 운전·교통수단, 혼자 있을 때의 안전 |
| 사회·공개 | 「뇌전증이 있다는 걸 다른 사람에게 알리거나 알리지 않는 것과 관련해 신경 쓰이는 일이 있나요?」 | 누구에게 말할지 정하는 기준, 오해, 불편한 대우, 숨기거나 피하는 상황 |
| 관계·가족 | 「가족이나 가까운 사람들과의 관계에서 뇌전증이 영향을 주는 부분이 있나요?」 | 가족의 반응, 역할 변화 |
| 자가관리·정보 | 「뇌전증을 이해하고 스스로 관리하는 데 어렵거나 더 알고 싶은 점이 있나요?」 | 정보를 얻는 곳, 약 챙기기, 발작이 생겼을 때 대처 |
| 병원 경험 | 「병원을 이용하거나 의료진과 이야기하는 과정에서 아직 말씀하지 않은 경험이 있나요?」 | 외래, 입원, 설명, 연속성 |
| 성·생식 건강 | 위 사전 문구를 읽은 뒤: 「연애, 성생활, 임신·출산, 가족계획과 관련해 뇌전증이나 치료와 연결되는 경험이 있다면 말씀해 주실 수 있을까요?」 | 해당한다고 할 때만 추가 probe |

성·생식 건강 사전 문구:

> 「다음은 조금 개인적인 내용일 수 있어서, 원하지 않으시면 답하지 않으셔도 됩니다.」

# 6. 우선순위와 마무리 (E–F단계) — 생략 금지

| # | 질문 (그대로 읽기) | 목적 |
|---|---|---|
| E1 | 「오늘 이야기해 주신 것 가운데, 병원에서 치료가 잘 되고 있는지를 살펴볼 때 꼭 물어봐야 한다고 생각하시는 것은 무엇인가요?」 | 측정 대상 도출 |
| E2 | 「오늘 말씀하신 여러 가지 중에서 1~3가지만 꼭 좋아져야 한다면 무엇을 고르시겠어요? 왜 그것인가요?」 | 우선순위 |
| E3 | 「제가 묻지는 않았지만 꼭 이야기하고 싶으셨던 내용이 더 있을까요?」 | 누락 보완 |
| E4 | 「오늘 질문 중에 이해하기 어려웠거나 불편했던 질문, 표현이 있었나요?」 | 면담지 개선 |
| E5 (선택) | 「뇌전증을 처음 진단받은 분께 본인의 경험을 바탕으로 한 가지만 이야기해 준다면, 어떤 말을 해 주고 싶으세요?」 | 환자 언어 |

마무리 문구:

> 「귀한 시간 내어 말씀해 주셔서 감사합니다. 오늘 이야기는 `[후속 안내: 결과 공유 방법 등]`. 면담 후에 궁금하거나 마음에 걸리는 점이 있으시면 `[연락처]`로 연락 주세요.」

- 녹음을 끄기 전에 환자의 상태를 확인하고, 필요하면 `[상담·안내 자료]`를 전달한다.

# 7. 면담 중 발작·정서적 고통 시 대응 `[연구팀·IRB 확정 필요]`

이 절은 근거 문헌이 아닌 일반 실무 초안이다. 연구팀과 IRB가 확정해야 한다.

| 상황 | 대응 초안 |
|---|---|
| 면담 중 발작 | 녹음 중지, 환자 안전 확보, 사전에 정한 응급 대응자 호출, 회복 후 면담 재개 여부는 환자 의사 확인, 사건 기록 |
| 눈물·강한 감정 | 잠시 멈춤, 「쉬었다 할까요?」, 계속·중단은 환자가 선택, 필요 시 상담 연계 |
| 위기 신호(자해 언급 등) | `[기관 위기 대응 절차]`에 따라 즉시 연구책임자 보고·연계 |
| 환자 요청 시 중단 | 즉시 중단, 사유 캐묻지 않기, 이미 수집한 자료의 처리는 동의서에 따름 |

# 8. 기록 방법

## 8.1 S / F / G 표시 (면담 후 transcript에 표시)

| 코드 | 의미 |
|---|---|
| S (Spontaneous) | §5 영역을 제시하기 전에 환자가 스스로 말함 |
| F (Focused) | 영역 1차 문장을 읽은 뒤 처음 나옴 |
| G (Gap-check) | 2차 예시를 든 뒤 나옴 |

G는 덜 중요하다는 뜻이 아니다. 도출 맥락을 기록하는 용도이다.

## 8.2 Field memo (면담 직후 10분 이내)

| 항목 | 기록 |
|---|---|
| 참여자 ID / 일시 / 방식 / 소요 시간 | |
| 자발적으로 나온 핵심 개념 (S) | |
| 새로운 개념, 예상 밖 내용 | |

# 11. 면담 시작 전 확정이 필요한 항목

1. 녹음 보관·삭제·비식별화 문구(IRB 승인본)와 동의서 일치 확인
2. §7 발작·정서적 고통 대응 절차 및 응급 대응자 지정
3. 포함·제외 기준(특히 인지 문제가 있는 환자의 포함 여부)과 표본 다양성 틀
4. 모의 면담·pilot 계획(면담자별 횟수, 첫 1–2건의 분석 포함 여부)
5. 면담자의 역할·소속과 연구 참여자와의 관계 기록 방식(COREQ 보고용)

7. 면담 소요 시간 실측 후 필수 질문 수 조정
